# CareerNexus

**Connecting Students, Skills & Opportunities.**

CareerNexus is a modern college placement management platform concept designed to connect students, recruiters and placement teams through one workflow.

## Current build

- Professional responsive landing page
- Student, Recruiter and Placement Officer entry points
- Placement analytics preview
- AI/NexusAI feature presentation
- Real-world placement workflow
- Responsive desktop/tablet/mobile design
- Demo login interaction

## Planned full-stack modules

- Role-based authentication
- Student profiles and resumes
- Recruiter/company management
- Placement drives and eligibility engine
- Applications and shortlist workflow
- Online assessments
- Interview scheduling
- Notifications
- Placement analytics
- AI resume analysis
- AI skill-gap analysis
- AI career recommendations
- NexusAI placement chatbot
- Resume builder
- PostgreSQL/Supabase database

## GitHub Pages

The current frontend is static and can be published with GitHub Pages.

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select **main** and **/ (root)**.
4. Save and wait for deployment.

The live URL will be:

`https://soniyareddy2468.github.io/career-nexus/`
